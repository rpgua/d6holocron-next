# Як долучитися до D6 Holocron NEXT

> **Мова:** [English](./CONTRIBUTE.md) | **Українська**

Дякуємо за інтерес до розвитку **D6 Holocron NEXT**! У цій інструкції описано, як правильно додавати нові книги, перекладати або доповнювати описи, вказувати посилання на файли та вносити зміни в код репозиторію.

## Як можна допомогти проєкту

- **Додавати нові книги Star Wars D6** (офіційні видання West End Games або значущі фанатські матеріали).
- **Додавати українські переклади або україномовні книги** (описи та/або посилання на PDF).
- **Виправляти й доповнювати метадані** (автори, ISBN, кількість сторінок, роки виходу, коди продуктів).
- **Покращувати інтерфейс, доступність, локалізацію або продуктивність сайту**.

## Як організовано контент книг

Файли книг зберігаються у `src/content/books/` з поділом на мовні папки:

```text
src/content/books/
├── en/<slug-книги>.md
└── uk/<slug-книги>.md
```

### Як взаємодіють `/en` та `/uk`
- **Англійська версія (`/en`)** показує всі книги з `src/content/books/en/`.
- **Українська версія (`/uk`)** показує всі книги з `src/content/books/uk/`, **а також** книги з `src/content/books/en/`, для яких ще немає окремого файлу в `uk/`.
- Якщо книга має **однакову назву файлу** в обох папках (наприклад, `my-book.md`), то на `/en` відображається англійський опис, на `/uk` — український, а перемикач `EN | UK` веде безпосередньо між ними.
- Якщо книга існує **лише** в `src/content/books/uk/`, вона з'явиться **тільки** на українській версії сайту (`/uk`) і не потрапить на `/en`.

## Додавання нової книги

### 1. Додайте обкладинку
Помістіть зображення обкладинки у відповідну підпапку в `src/assets/covers/` (наприклад, `src/assets/covers/Supplements/My Book.webp`).
- Бажаний формат — `.webp` (під час збірки Astro автоматично згенерує оптимізовані мініатюри та JPEG-прев'ю для `og:image`).

### 2. Створіть Markdown-файл(и)
Називайте файли в `kebab-case`:
- Англійська версія: `src/content/books/en/<slug-книги>.md`
- Український переклад (або книга лише українською): `src/content/books/uk/<slug-книги>.md`

Увесь поділ на категорії та видання задається у frontmatter (`category` та `edition`) — не створюйте вкладених підпапок усередині `en/` чи `uk/`.

### 3. Опис полів frontmatter

Усі поля перевіряються під час збірки схемою Zod у `src/content.config.ts`:

| Поле | Обов'язкове | Тип / допустимі значення | Примітка |
| --- | --- | --- | --- |
| `title` | **Так** | `string` | Офіційна назва книги |
| `description` | **Так** | `string` (**макс. 160 символів**) | Короткий опис для сторінки та SEO-тегів |
| `edition` | **Так** | `'1E' \| '2E' \| '2E-RE' \| 'REUP' \| 'OpenD6'` | Видання системи правил |
| `category` | **Так** | `'core' \| 'sourcebook' \| 'adventure' \| 'supplement'` | Категорія в каталозі |
| `publisher` | Ні | `string` (за замовчуванням: `'West End Games'`) | Видавництво або спільнота |
| `author` | Ні | `string \| string[]` | Один автор або YAML-список авторів |
| `releaseYear` | Ні | `integer` | Рік видання (наприклад, `1994`) |
| `productCode` | Ні | `string` | Код продукту (наприклад, `WEG40055`) |
| `isbn` | Ні | `string` | ISBN-10 або ISBN-13 |
| `pages` | Ні | `integer` | Кількість сторінок |
| `cover` | Ні | відносний шлях до зображення | Від `.md`-файлу до `src/assets/covers/...` (зазвичай `../../../assets/covers/...`) |
| `languages` | Ні | `Array<'en' \| 'uk'>` | Мови доступних PDF-файлів (наприклад, `["en"]` або `["en", "uk"]`) |
| `downloads` | Ні | `{ en?: ..., uk?: ... }` | Прямі посилання на завантаження за мовами (один URL або масив `{ url, label? }`) |

### 4. Приклад файлу книги

```markdown
---
title: "Star Wars: The Roleplaying Game, Second Edition"
description: "Основна книга правил 2-го видання 1992 року з Диким кубиком, оновленим боєм та розширеними правилами Сили."
edition: "2E"
category: "core"
publisher: "West End Games"
author: "Bill Smith"
releaseYear: 1992
productCode: "WEG40055"
isbn: "0-87431-181-0"
pages: 176
cover: "../../../assets/covers/Core Rule Books/The Roleplayng Game Second Edition Oct 1992 WEG40055 (WEG40055).webp"
languages: ["en"]
downloads:
  en: "https://archive.org/download/swd6-holocron-archive/Core%20Rule%20Books/The%20Roleplayng%20Game%20Second%20Edition%20Oct%201992%20WEG40055%20%28WEG40055%29.pdf"
---

Стислий і фактичний огляд книги: контекст видання, епоха сеттингу та призначення для гравців і ведучих.

## Основний зміст

- Конкретні розділи, пригоди, шаблони персонажів, кораблі або ігрові механіки.
```

#### Додавання кількох файлів або українського PDF

```yaml
languages: ["en", "uk"]
downloads:
  en: "https://archive.org/download/..."
  uk:
    - label: "Книга правил PDF"
      url: "https://archive.org/download/..."
    - label: "Аркуш персонажа"
      url: "https://archive.org/download/..."
```

> **Порада:** Якщо ви додаєте український PDF до вже наявної англійської книги, оновіть `languages` (додайте `"uk"`) і `downloads.uk` в **обох** файлах (`en/` та `uk/`), щоб відвідувачі обох мовних версій бачили всі доступні файли для завантаження.

## Внесок у код та інтерфейс

- **Локалізація інтерфейсу**: додавайте нові рядки інтерфейсу одночасно в `src/i18n/en.ts` та `src/i18n/uk.ts` з однаковими ключами.
- **Семантичні кольори daisyUI 5**: використовуйте семантичні класи (`bg-base-100`, `bg-base-200`, `text-base-content`, `border-base-300`, `primary`) замість жорстких кольорів чи `dark:`, щоб усі теми працювали автоматично.
- **Мінімум клієнтського JS**: віддавайте перевагу статичним `.astro`-компонентам.
- **Шляхи з урахуванням `base` та `trailingSlash: 'never'`**: завжди формуйте внутрішні посилання через `localizePath()` (`src/i18n`) або `withBase()` (`src/utils/paths`).

## Порядок подання Pull Request

1. Зробіть форк репозиторію та створіть окрему гілку (наприклад, `feat/add-book-name` або `fix/metadata-typo`).
2. Внесіть зміни та запустіть повну збірку локально:
   ```bash
   npm run build
   npm run preview
   ```
3. Переконайтеся, що:
   - `npm run build` завершується без помилок (це автоматично перевіряє Zod-схему, шляхи до обкладинок, довжину `description` ≤ 160 символів та валідність URL у `downloads`).
   - Обидві версії (`/d6holocron-next/en/...` та `/d6holocron-next/uk/...`) коректно відображаються у `npm run preview`.
   - Нова книга відображається в каталозі, на сторінці категорії та знаходиться через пошук Pagefind у навбарі.
4. Відкрийте Pull Request із коротким описом внесених змін.
